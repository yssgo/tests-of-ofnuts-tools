ofn-path-marquee
================

## 목적

이 스크립트는 경로 하나로부터 마키(marquee) 스타일로 움직이는 점선을 생성하는 데
필요한 모든 프레임을 렌더링합니다.

이 경로는 텍스트 레이어에서 ::레이어 &rarr; 텍스트를 경로로::{.menupath}를 사용하여 얻을 수도 있습니다.

![애니메이션](./images/Gimp.webp)

다른 소스를 사용할 수도 있습니다. 웹 사이트 속도가 느릴 경우 "스피너"를 생성하는 좋은 방법입니다.

![스피너](./images/Spinner.webp)


## 작동 방식

이 스크립트는 경로 목록 메뉴에서 대상 경로를 우클릭 한 후
::렌더링 &rarr; 마키 애니메이션::{.menupath} 항목을 선택하여 시작합니다.

이 스크립트는 ::편집 &rarr; 경로대로 획 긋기::{.menupath}와 같은 `선` 모드로 경로를 따라 획을 긋고,
각 프레임마다 점선 오프셋[^1]을 조정합니다. 경로에 현재 전경색으로 획이 그어집니다.

[^1]: dash offset(역주: 점선 시작 위치)

### 주의 사항

이미지에 레이어나 채널이 적어도 하나가 없으면 대부분의 메뉴가 비활성화됩니다.
더미 ""레이어""를 추가하면 애니메이션을 내보내기 전에(또는 '재생' 필터로 테스트하기 전에조차)
해당 레이어를 삭제해야 하고, 이 스크립트를 또 한 번 실행하려면 더미 레이어를
다시 추가해야 한다는 단점이 있습니다. 더미 ""채널""을 추가하는 것이 더 나은 해결 방법입니다.

-   채널 목록을 엽니다.
-   우클릭 메뉴를 열고 '새 채널...'을 선택합니다.
-   채널 매개변수는 중요하지 않습니다.
-   눈 모양 아이콘을 클릭하여 채널을 숨깁니다.

모든 메뉴가 다시 비활성화되면, 채널 목록으로 이동하여 더미 채널을 다시 선택합니다.

## 매개변수

-   `방향 반전`: 애니메이션을 반대 방향으로 움직입니다.
    기본적으로 애니메이션은 경로 앵커가 나열된 순서대로 움직이지만,
    경로가 ::레이어  &rarr;  텍스트를 경로로::{.menupath}의 출력인 경우 이 동작을 제어하기 어려울 수 있습니다.
    모든 획  또는 특정 획을 반전시키려면 제 스크립트 'ofn-path-edits'를 사용할 수 있습니다.

-   `주기 길이`: 대시+공백 단위의 길이입니다. 이 값은 각 획의 길이를 정확히 나누도록
    미묘하게 조정되어, 닫힌 획에서 보기 흉한 현상이 발생하는 것을 방지합니다.

-   `비율`: 대시+공백 단위에서 대시의 상대적인 길이입니다.
    이 값은 "기본(raw)" 대시 길이를 설정하므로 "마개(cap)" 스타일을 사용하면
    대시가 이 값을 초과하여 연장될 수 있습니다.

-   '단계 수': 패턴을 정확히 한 주기만큼 이동시키는 애니메이션 총 단계 수입니다.

-   `선 폭`: 선의 두께(픽셀 단위)
-   `마개(cap) 스타일`, `이음(join) 스타일`, `뾰족뿔(miter) 제한`, `계단 현상 제거(antialiasing)`:
    ::![web](external_link_icon.svg)
    [일반적인 경로 획 긋기 옵션](https://docs.gimp.org/en/gimp-using-paths-stroking.html)::{.link-with-icon}.
    `뭉툭하게(Butt)` 스타일을 제외한 마개 스타일은
    대시의 양쪽 끝을 선 폭의 절반만큼 확장한다는 점에 유의하세요.
-  `불투명도`: 렌더링(그려 내기)의 불투명도

-   `배경`: 경로가 렌더링되기 전에 레이어를 색으로 채우는 방식
-   `레이어 이름`: 레이어 이름을 지정하는 패턴(아래 참조)

#### 레이어 이름 패턴

레이어 이름 패턴은 특정 처리 데이터를 사용하여 레이어 이름을 지정하는 방법을 지정합니다.
패턴에서, 중괄호 안의 이름은 해당 경로에 대한 데이터의 값으로 교체됩니다.
예를 들어, 패턴 `Frame-{step1}/{count}`는 50단계 중 세 번째 단계에 대해
`Frame-3/50`이라는 이름을 생성합니다.

사용 가능한 값은 다음과 같습니다.

-   `pathName`: 원본 경로 이름
-   `count`: 총 단계 수
-   `step0`, `step1`: 단계 번호.

    `step0`은 0부터 시작하고(컴퓨터가 세는 방식),
    `step1`은 1부터 시작합니다(사람이 세는 방식).

- `period`: 하이픈+공백 주기의 길이(픽셀 단위)
- `ratio`: 주기에 대한 대시의 비율(1~99)

이름 패턴은 실제로 파이썬 형식 지정자(specification)로 직접 사용되므로 수정자를 사용할 수 있습니다.
숫자에 가장 유용한 수정자는 0으로 채워진 최소 길이를 정의하는 기능입니다.
이는 중괄호 안의 변수 이름에 `:0Nd`를 추가하여 수행합니다.
예를 들어, `{step1:03d}`는 단계 번호를 최소 세 자리 숫자로 삽입하고 필요한 경우 왼쪽에 0을 추가합니다.
예: `001`, `013`, `099`, `100`.
