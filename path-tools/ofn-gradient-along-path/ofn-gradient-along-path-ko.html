English

ofn-gradient-along-path

목적

ofn-gradient-along-path는, 현재 그라디언트를 사용하여, 경로 획들을 따라 가로로 이중 선형 혼합을 그립니다.

원리

그라디언트는 너비를 줄이면서 경로대로 획을 그어서 렌더링되고, 대응하는 위치에서 그라디언트를 샘플링(표본 추출)하여 색상을 설정합니다.

레이어에서, 그라디언트가 완전히 불투명하지 않으면, 레이어에 마스크가 추가되고 그라디언트의 불투명도 부분에 비슷한 방식으로 획을 긋습니다. 그런 다음 마스크가 레이어에 적용됩니다.

사용법

이 스크립트는 경로 목록에서 경로의 우클릭 메뉴(Ofnuts → 장식 → 경로를 따라 그라디언트...)에서 찾을 수 있습니다. 그라디언트는 활성 드로어블(레이어, 레이어 마스크, 채널, 퀵마스크 등)에 그려집니다.

매개변수

  • 폭: 획의 전체 너비(픽셀 단위)입니다(경로 양쪽은 각각 폭÷2).
  • 뒤집힌 그라디언트: '아니요'이면 그라디언트가 안쪽에서 바깥쪽으로 매핑되고, '예'이면 바깥쪽에서 안쪽으로 매핑됩니다.
  • 정밀도: 렌더링의 정밀도입니다. 세밀한 렌더링들1 은 각 획을 이전 획보다 1픽셀씩 작게 만듭니다(양 쪽에 0.5픽셀씩). 현재 설정은 0.5, 1, 2, 5, 10픽셀입니다. 높은 정밀도는 획 긋기 과정이 더 많이 필요합니다.
  • 마개 모양새, 이음 모양새 및 뾰족뿔 제한 : 획 선 옵션입니다 (자세한 내용은 Ofnuts → 편집 → 경로에 획 긋기문서를 참조하십시오). 값이 현재 이면 스크립트가 Gimp에 현재 설정된 값을 사용함을 의미합니다. 뾰족뿔 제한 설정은 이음 모양새가 명시적으로 뾰족뿔로 설정된 경우에만 사용됩니다.

사용상 주의 사항

  • 작동 원리상 투명도를 구현하려면 마스크를 사용해야 하므로, 투명도가 있는 그라디언트는 다음에 대해서는 사용할 수 없습니다.

    • 채널(퀵 마스크 포함)
    • 레이어 마스크
    • 이미 마스크가 있는 레이어

  • 그라디언트의 불투명도는 레이어의 불투명도를 설정합니다. 그라디언트는 기존 픽셀 위에 덧그리는 것이 아닙니다. 그다디언트가 해당 픽셀을 완전히 바꿉니다.

  • 경로를 사용하여 선택 영역을 만들면 그라디언트의 절반만 렌더링할 수 있습니다.
